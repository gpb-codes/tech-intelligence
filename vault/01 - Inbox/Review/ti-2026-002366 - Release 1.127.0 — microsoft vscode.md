## 📊 Informe para desarrolladores

> [!info] ¿Qué es?
>
> Visual Studio Code (VS Code) es un editor de código fuente gratuito y de código abierto desarrollado por Microsoft, basado en la arquitectura Electron. Ofrece herramientas integradas para edición, depuración, control de versiones y una amplia extensión de complementos para múltiples lenguajes y frameworks.

> [!tip] ¿En qué ayuda al desarrollo?
>
> Facilita el desarrollo de software al proporcionar un entorno ligero pero potente. Su ecosistema de extensiones, depuración integrada y control de versiones nativo optimizan la productividad y permiten personalizar flujos de trabajo para casi cualquier tecnología moderna.

# Release: v1.18.9 — sst/opencode

<span class="ti-runes">ᚠ ᚢ ᚦ ᚨ ᚱ ᚲ</span>

`⚪ Baja` · `🌱 Bajo`

| Campo | Valor |
| --- | --- |
| Producto | **opencode** |
| Versión | v1.18.9 |

> [!abstract] Resumen
>
> - Se lanzó la versión **v1.18.9** de **sst/opencode**.
> - **Core**: Se restauró la compatibilidad con clientes legacy del SDK MCP.
> - **Desktop**: Se corrigió un fallo en la limpieza de Solid que rompía la navegación y se solucionó la carga de la sesión home para permitir actualizaciones sin suspender la página.
> - **Desktop**: Se eliminaron bordes verticales extra en la vista de proyectos V2, se agregó una sidecar V2 opt-in respaldada por el CLI bundled y se implementaron secciones de proveedores de modelo colapsables en ajustes V2.
> - Incluye una contribución comunitaria (@roborew) para preservar plugins de scroll esenciales en @dnd-kit/solid.

## ¿Qué ocurrió? ⚔️

> [!info] Traducción del anuncio
>
> Lanzamiento: v1.18.9 — sst/opencode
> 
> ## Core ### Bugfixes - Restauró la compatibilidad con clientes legacy MCP SDK. ## Desktop ### Bugfixes - Corregido un fallo en la limpieza de Solid que podría romper la navegación en la aplicación de escritorio. - Corregida la carga de sesión home para que la lista de sesiones pueda actualizarse sin suspender toda la página. ### Improvements - Eliminados los bordes verticales extra de la vista de proyectos V2 home. - Agregada una sidecar V2 opt-in de escritorio respaldada por el servicio CLI bundled. - Agregadas secciones de modelo provider colapsables en ajustes V2. **Gracias a 1 colaborador de la comunidad:** - @roborew: - fix(desktop): patch @dnd-kit/solid to preserve core scroll plugins (#38119)

## 📜 Informe para desarrolladores

> [!info] ¿Qué es?
>
> OpenCode (sst/opencode) es un agente de IA para programación con interfaz de terminal y aplicación de escritorio. Su entorno utiliza SolidJS para gestionar sesiones, modelos y conectores MCP de forma visual.

> [!tip] ¿En qué ayuda al desarrollo?
>
> Acelera el desarrollo de software al automatizar tareas de código y gestionar contexto mediante servidores MCP. Las mejoras en la UI y compatibilidad con SDKs legacy aseguran flujos de trabajo estables sin interrupciones.

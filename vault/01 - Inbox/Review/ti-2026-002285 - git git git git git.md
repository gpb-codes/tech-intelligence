## 📜 Informe para desarrolladores

> [!info] ¿Qué es?
>
> Git es un sistema de control de versiones distribuido que permite rastrear cambios en el código fuente y coordinar el trabajo entre desarrolladores.

> [!tip] ¿En qué ayuda al desarrollo?
>
> Facilita la colaboración, el historial de cambios, la ramificación y fusión, y la gestión de versiones, esenciales para el desarrollo de software moderno.

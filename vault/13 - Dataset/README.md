# 13 - Dataset

Aquí se exporta el dataset en JSONL (una línea = un objeto JSON):

- `all.jsonl` — todos los registros
- `updates.jsonl` — todas las actualizaciones
- `tools.jsonl` — herramientas / developer tools
- `models.jsonl` — modelos de IA
- `companies.jsonl` — empresas
- `alternatives.jsonl` — alternativas detectadas

Los archivos se regeneran automáticamente en cada `sync` / `export`.

Uso futuro previsto: RAG, fine-tuning experimental, búsqueda semántica, análisis y agentes.

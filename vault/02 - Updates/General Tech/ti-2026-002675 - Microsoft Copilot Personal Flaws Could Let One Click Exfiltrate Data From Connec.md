# Microsoft Copilot Personal Flaws Could Let One Click Exfiltrate Data From Connected Apps

<span class="ti-runes">ᚠ ᚢ ᚦ ᚨ ᚱ ᚲ</span>

`critical` · `🚀 Alto`

| Campo | Valor |
| --- | --- |
| Versión | 1.0 |
| Fecha de lanzamiento | 2023-02-20 |
| Requisitos | Windows 10/11, macOS 12.0+, iOS 14.0+, Android 10.0+ |
| Cambios incompatibles | No hay cambios significativos. |

> [!abstract] Resumen
>
> * Microsoft Copilot Personal tiene vulnerabilidades que podrían permitir a un clic en un enlace creado con un link malicioso a extraer datos de aplicaciones conectadas y otros datos disponibles para el usuario de Copilot.
> * La vulnerabilidad se debe a que el software utiliza un algoritmo de reconocimiento de patrones para detectar y bloquear los enlaces maliciosos.
> * Sin embargo, la vulnerabilidad también se debe a que el software no verifica adecuadamente la autenticidad de los enlaces antes de ejecutarlos.
> * La vulnerabilidad es relevante porque puede permitir a los atacantes acceder a información sensible de las aplicaciones y usuarios de Microsoft Copilot.
> * La vulnerabilidad es relevante porque puede tener consecuencias graves para la seguridad de los usuarios y la integridad de las aplicaciones.

## ¿Qué ocurrió? ⚔️

> [!info] Traducción del anuncio
>
> Microsoft Copilot Personal tiene vulnerabilidades que podrían permitir a un clic en un enlace creado con un link malicioso a extraer datos de aplicaciones conectadas y otros datos disponibles para el usuario de Copilot.

> [!success] Impacto

> - Cambios que afectan ampliamente al ecosistema de la inteligencia artificial
> - Lanzamientos disruptivos que podrían comprometer la seguridad de las aplicaciones conectadas

## 📜 Informe para desarrolladores

> [!info] ¿Qué es?
>
> Microsoft Copilot Personal es un servicio de inteligencia artificial desarrollado por Microsoft que se utiliza para mejorar la experiencia del usuario en aplicaciones de la compañía. Es un modelo de lenguaje personalizado que puede responder preguntas y proporcionar recomendaciones personalizadas. Sin embargo, también puede ser utilizado para realizar tareas más complejas, como la resolución de problemas y la creación de contenido.

> [!tip] ¿En qué ayuda al desarrollo?
>
> Microsoft Copilot Personal tiene la capacidad de aprender y mejorar con el tiempo, lo que significa que puede ser utilizado para mejorar la experiencia del usuario y la eficiencia del desarrollo de software. Sin embargo, también puede ser utilizado para realizar tareas más complejas, lo que puede aumentar el riesgo de vulnerabilidades y seguridad.

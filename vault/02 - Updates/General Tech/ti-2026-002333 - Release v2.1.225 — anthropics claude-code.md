## ¿Qué ocurrió? ⚔️

> [!info] Traducción del anuncio
>
> Releases:
> - v2.1.225 — anthropics/claude-code
> 
> ¿Qué ha cambiado - Agregó soporte para la limitación de gastos de gateway en Claude Code; el mensaje de limitación ahora menciona el límite, su fecha de reset y la mensaje del operador (requiere la gateway en v2.1.225) - Agregó una llamada de trabajo de seguridad para `claude agentos` para directorios no confiables, lo mismo que `claude` - Se resolvió un error temporal 401 reemplazando un token de autenticación prolongado por un token de inicio breve almacenado, interrumpiendo sesiones en headless hasta la restart - Se resolvió MCP OAuth servidores en macOS intermitentemente fallando con un brote de 401 errores, como si nunca estuviera autenticado, después de un lector de claves fallido - Se resolvió el modo auto reflejando una negación de permiso hacia la limitación consecutiva; el acción es aún negada, pero el modelo está ahora diciendo que se mueve en lugar de intentar; - Se resolvió las conversaciones de mensaje cruzado que quedaban estancadas sin notificación ni cadencia en sesiones de control remoto y durante la startup - Se resolvió que las conversaciones de mensaje se quedaban "frescas" sin notificación ni cadencia en sesiones de control remoto y durante la startup - Se resolvió que el `claude self-hosted-runner` registraba y luego fallaba cada sesión cuando `--base-dir` no podía ser creado o escrito; ahora se exite en startup con un error claro - Se resolvió que Claude Code en las sesiones remotas se mostraba como "estancado" re-sendería una backlog de eventos creciente en cada reconnect - Se mejoró Remote Control: fotos adjuntadas desde el Claude se muestran directamente a Claude en lugar de ser leídas de la carpeta con un llamado separado para la herramienta; - [VSCode] Se resolvió que el foco se despliega hacia la lista de tareas reciente, el contexto de la pregunta pendiente y las respuestas; se despliega solo las respuestas "Por pensamiento" y se re-collapse cuando su turno se completa - Se permitió iniciar una conversación con las sesiones de control remoto de otros machines por nombre (`ListAgents` muestra que son `name [ref]`), en lugar de solo responder después de que la persona que se envía la primera respuesta; - Se permitió que la persona que se confirma ya sea no se cambie a un mismo nombre de sesión en la misma máquina cuando su lista no se puede verificar; cuando su propia lista no se puede verificar

## What's changed - Added gateway spend-limit support to Claude Code's usage warning; the limit-reached message now names the cap, its reset time, and the operator's message (requires the gateway on 2.1.225) - Added a workspace trust prompt to `claude agents` for untrusted directories, matching the behavior of `claude` - Fixed a transient 401 replacing a long-lived `CLAUDE_CODE_OAUTH_TOKEN` with a stored login's short-lived token, breaking headless sessions until restart - Fixed MCP OAuth servers on macOS intermittently failing with a burst of 401 errors, as if never authenticated, after a keychain read timed out - Fixed auto mode counting a safety-filter refusal of its own permission check toward the consecutive-block limit; the action is still denied, but the model is now told to move on rather than retry - Fixed cross-session messages staying parked without a notice or expiry in headless sessions and during startup - Fixed conversation history breaking on Remote Control session resume after very large conversations were compacted - Fixed hovering over a session in another project in the agents list changing the directory the next agent starts in - Fixed `claude self-hosted-runner` registering and then failing every session when `--base-dir` cannot be created or written; it now exits at startup with a clear error - Fixed Claude Code on the web sessions being misreported as stuck, re-sending a growing event backlog on every reconnect - Improved Remote Control: photos attached from the Claude app are now shown to Claude directly instead of being read from disk with a separate tool call - [VSCode] Fixed Focus view folding away the latest to-do list, a pending question's context, and settled answers; thinking-only folds show "Thought for Ns" and re-collapse when their turn completes - SendMessage can now start a conversation with your Remote Control sessions on other machines by name (`ListAgents` shows them as `name [ref]`), instead of only replying after they message you first - SendMessage: a Remote Control recipient you already confirmed is never swapped for a same-named session on this machine when its own list couldn't be checked

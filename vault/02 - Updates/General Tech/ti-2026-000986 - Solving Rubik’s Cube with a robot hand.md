## ¿Qué ocurrió? ⚔️

> [!info] Traducción del anuncio
>
> Solving Rubik’s Cube with a robot hand
> 
> Hemos entrenado dos redes neuronales para resolver el cubo de Rubik con una mano robótica similar a la de un humano. Estas redes neuronales están entrenadas completamente en simulación, utilizando el código de aprendizaje de reinforcement de OpenAI Five combinado con un nuevo método llamado Randomización Doméstica (ADR). El sistema puede manejar situaciones que nunca vio durante el entrenamiento, como ser proyectado por un perro de peluche. Esto muestra que el aprendizaje de reinforcement no es solo un herramienta para tareas virtuales, sino que puede resolver problemas físicos que requieren una mayor dexterity.

We’ve trained a pair of neural networks to solve the Rubik’s Cube with a human-like robot hand.

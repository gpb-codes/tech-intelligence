> [!abstract] Resumen
>
> *   **Modelo Distillado**: Un modelo distillado es una versión más pequeña y eficiente de un modelo de aprendizaje automático, que se obtiene mediante un proceso de distillación que elimina información innecesaria.
> *   **API OpenAI**: La API OpenAI es una plataforma de desarrollo de aplicaciones que permite a los desarrolladores crear y desplegar aplicaciones personalizadas para una variedad de tareas, incluyendo la creación de modelos de aprendizaje automático.
> *   **Fine-tuning**: Fine-tuning es el proceso de ajustar un modelo pre-entrenado para adaptarlo a un nuevo conjunto de datos. En este caso, se fine-tunará un modelo distillado costoso con los resultados de un modelo de frontera grande.
> *   **Plataforma OpenAI**: La plataforma OpenAI ofrece una variedad de herramientas y servicios para desarrolladores, incluyendo la creación de modelos de aprendizaje automático, la fine-tuning y la integración con otras plataformas.
> *   **Relevancia**: Fine-tuning un modelo distillado costoso con los resultados de un modelo de frontera grande es relevante para aplicaciones que requieren una alta precisión y eficiencia en la toma de decisiones.

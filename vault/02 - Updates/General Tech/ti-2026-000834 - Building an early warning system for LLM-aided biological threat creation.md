# Building an early warning system for LLM-aided biological threat creation

<span class="ti-runes">ᚠ ᚢ ᚦ ᚨ ᚱ ᚲ</span>

`critical` · `🚀 Alto`

> [!abstract] Resumen
>
> *   Estudio que involucró a expertos en biología y estudiantes para evaluar el riesgo de que un modelo de lenguaje grande (LLM) pueda ayudar a alguien a crear una amenaza biológica.
> *   Hallazgo de que GPT-4 aumenta la precisión de la creación de amenazas biológicas, aunque no es suficiente para ser concluyente.
> *   El aumento en la precisión no es lo suficientemente grande como para ser concluyente, lo que sugiere que el modelo de lenguaje puede ser utilizado para crear amenazas biológicas.
> *   El estudio es un punto de partida para la investigación y la deliberación comunitaria continua sobre el uso de modelos de lenguaje para crear amenazas biológicas.
> *   El hallazgo no es suficiente para determinar si un modelo de lenguaje puede ser utilizado para crear amenazas biológicas, y más allá de esto, no es suficiente para determinar si el uso de modelos de lenguaje para crear amenazas biológicas es ético.

## ¿Qué ocurrió? ⚔️

> [!info] Traducción del anuncio
>
> Building un sistema de advertencia temprana para modelos de lenguaje LLM-aided biological threat creation
> 
> Estamos desarrollando un plan para evaluar el riesgo de que un modelo de lenguaje grande (LLM) pueda ayudar a alguien a crear una amenaza biológica. En un estudio que involucró a expertos en biología y estudiantes, encontramos que GPT-4 proporciona un aumento máximo en la precisión de la creación de amenazas biológicas. Aunque este aumento no es lo suficientemente grande como para ser concluyente, este hallazgo es un punto de partida para la investigación y la deliberación comunitaria continua.

## ¿Por qué importa? 🛡️

> [!success] Impacto
>
> - El aumento en la precisión de la creación de amenazas biológicas puede tener implicaciones serias para la seguridad y la salud pública.
> - El hallazgo puede ser un punto de partida para la investigación y la deliberación comunitaria continua sobre el uso de modelos de lenguaje en la creación de amenazas biológicas.
> - El aumento en la precisión de la creación de amenazas biológicas puede ser un indicador de un cambio significativo en la capacidad de los modelos de lenguaje para crear amenazas biológicas.

## 📜 Informe para desarrolladores

> [!info] ¿Qué es?
>
> Un sistema de advertencia temprana para modelos de lenguaje LLM-aided biological threat creation, diseñado para ayudar a prevenir la creación de amenazas biológicas a través de la evaluación del riesgo de estos modelos en entornos de biología.

> [!tip] ¿En qué ayuda al desarrollo?
>
> Este sistema busca proporcionar una herramienta para expertos y estudiantes en biología, así como para la comunidad en general, para evaluar y mitigar el riesgo de que los modelos de lenguaje grandes ayuden a crear amenazas biológicas. Al proporcionar una advertencia temprana, se puede prevenir la creación de nuevas amenazas biológicas.

We’re developing a blueprint for evaluating the risk that a large language model (LLM) could aid someone in creating a biological threat. In an evaluation involving both biology experts and students, we found that GPT-4 provides at most a mild uplift in biological threat creation accuracy. While this uplift is not large enough to be conclusive, our finding is a starting point for continued research and community deliberation.

# Microsoft confirms outage affecting search in Microsoft 365 apps

<span class="ti-runes">ᚠ ᚢ ᚦ ᚨ ᚱ ᚲ</span>

`critical` · `🌐 Medio`

> [!abstract] Resumen
>
> *   Microsoft confirma outage afectando la búsqueda en aplicaciones de Microsoft 365.
> *   La búsqueda en aplicaciones de Microsoft 365 se ha suspendido debido a un problema técnico.
> *   El problema afecta a los usuarios de Microsoft 365 que utilizan la búsqueda en aplicaciones como Outlook, Word, Excel, etc.
> *   La empresa Microsoft ha informado que se está trabajando para solucionar el problema y restaurar la búsqueda en las aplicaciones.
> *   El outage se ha iniciado en la mañana de hoy y se espera que se resuelva pronto.

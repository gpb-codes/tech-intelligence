> [!abstract] Resumen
>
> *   Git es un sistema de gestión de versiones de código abierto y escalable.
> *   Fue creado por Linus Torvalds en 2005 y se ha convertido en uno de los sistemas de gestión de versiones más populares del mundo.
> *   Es utilizado en proyectos de código abierto, como Linux, y en entornos de desarrollo de software.
> *   Proporciona funcionalidades como la gestión de paquetes, la gestión de dependencias, la gestión de cambios y la gestión de versiones.
> *   Es compatible con múltiples sistemas operativos, incluyendo Windows, macOS y Linux.

## 📜 Informe para desarrolladores

> [!info] ¿Qué es?
>
> La tecnología Git es una herramienta de gestión de versiones y control de cambios que permite a los desarrolladores y los equipos colaborativos compartir y trabajar en proyectos de manera segura y eficiente.

> [!tip] ¿En qué ayuda al desarrollo?
>
> Git permite a los desarrolladores crear y mantener múltiples versiones de un proyecto de manera segura y controlada, lo que facilita la colaboración y el desarrollo de software de manera más eficiente.

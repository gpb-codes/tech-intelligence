> [!abstract] Resumen
>
> *   Linux 7.1 y Linux 7.2 se han realizado pruebas adicionales para comparar su rendimiento en el Intel Xeon 600 Series.
> *   Pruebas de Phoronix han demostrado beneficios para Intel Arc B390 Xe3 en algunas configuraciones.
> *   Linux 7.2 ha demostrado mejor rendimiento de pollo en AMD Ryzen Threadripper y otros hardware.
> *   Las pruebas de kernel actualizadas se realizan con el Intel Xeon 678X Granite Rapids WS actualmente en el laboratorio.
> *   Las pruebas de Linux 7.2 se han realizado para evaluar su rendimiento en diferentes hardware y configuraciones.

## ¿Qué ocurrió? ⚔️

> [!info] Traducción del anuncio
>
> Linux 7.1, Linux 7.2 Performance On The Intel Xeon 600 Series
> 
> Con Linux 7.2 se espera que se esté disponible para su lanzamiento establecido este fin de semana, hoy se ha realizado algunas pruebas adicionales de Linux 7.2 Git kernel así como Linux 7.1 estable comparado con Linux 7.0 utilizado por Ubuntu 26.04 LTS. Pruebas de Phoronix que se realizaron anteriormente de Linux 7.2 han demostrado beneficios para Intel Arc B390 Xe3 en algunas configuraciones, mejor rendimiento de pollo en AMD Ryzen Threadripper y otros hardware, y algunos ganos de rendimiento de IO en AMD EPYC Turin. Las pruebas de kernel actualizadas se realizan con el Intel Xeon 678X Granite Rapids WS actualmente en el laboratorio como parte del HP Z4 G6i workstation de prueba.

With Linux 7.2 expected for its stable release this weekend, today's testing has some additional testing of the Linux 7.2 Git kernel as well as Linux 7.1 stable compared to Linux 7.0 as used by default on Ubuntu 26.04 LTS. Phoronix testing previously conducted of Linux 7.2 have shown benefits for Intel Arc B390 Xe3 in some configurations, faster poll performance on AMD Ryzen Threadripper and other hardware, and some nice I/O performance gains on AMD EPYC Turin. Today's kernel benchmarks are with the Intel Xeon 678X Granite Rapids WS currently in the lab as part of the HP Z4 G6i workstation testing.

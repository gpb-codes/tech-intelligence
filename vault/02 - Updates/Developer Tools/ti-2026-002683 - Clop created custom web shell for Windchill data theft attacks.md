> [!abstract] Resumen
>
> *   El Clop creó un shell web personalizado para ataques de robo de datos de Windchill.
> *   Este shell web permitía a los atacantes acceder a la información de Windchill sin necesidad de tener acceso remoto al sistema.
> *   La implementación del shell web personalizado permitió a los atacantes realizar acciones de robo de datos sin ser detectados.
> *   La vulnerabilidad se debió a la falta de actualización y mantenimiento adecuados del software.
> *   La vulnerabilidad se utilizó para realizar ataques de robo de datos y obtener información confidencial.

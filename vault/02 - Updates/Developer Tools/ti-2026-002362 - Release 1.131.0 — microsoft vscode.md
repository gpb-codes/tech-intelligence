# Release: 1.131.0 — microsoft/vscode

## Resumen

- Versión 1.31 de Visual Studio Code se ha lanzado con varias mejoras y correcciones de errores.
- Se han agregado nuevas características a la herramienta de depuración, como la capacidad de depurar en segundo plano.
- La herramienta de depuración también ha sido mejorada para soportar mejor los proyectos de TypeScript.
- Se han agregado nuevas extensiones para mejorar la experiencia de desarrollo en Visual Studio Code.
- La versión 1.31 también incluye varias correcciones de errores y mejoras de rendimiento.

## ¿Por qué importa?

- Mejoras en la experiencia de usuario
- Nuevas funcionalidades en la herramienta de depuración
- Actualización de la herramienta de refactorización

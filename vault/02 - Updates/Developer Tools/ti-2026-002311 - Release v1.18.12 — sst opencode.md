# Release: v1.18.12 — sst/opencode

<span class="ti-runes">ᚠ ᚢ ᚦ ᚨ ᚱ ᚲ</span>

`🟡 Media` · `🌐 Medio`

| Versión | v1.18.12 |
| Open source | ✅ Sí |

> [!abstract] Resumen
>
> - Lanzamiento de la versión v1.18.12 de sst/opencode.  
> - Core: Se solucionó el fallo en solicitudes de completado Azure GPT-5.5+ cuando el razonamiento está habilitado.  
> - Desktop: Se redujo el lag del compositor al incluir imágenes o attachments grandes.  
> - Desktop: La búsqueda de proyectos ahora coincide con cualquier proyecto reciente conocido, no solo los primeros cinco.  
> - Desktop: Se eliminaron errores de asistente obsoletos de la línea al reanudar el streaming y se omitieron lecturas de configuración legacy contra servidores v2 para evitar cargas espurias.

## ¿Qué ocurrió? ⚔️

> [!info] Traducción del anuncio
>
> Release: v1.18.12 — sst/opencode
> 
> ## Core ### Bugfixes - Fixed Azure GPT-5.5+ completion requests failing when reasoning is enabled. (@frederiknsgo) ## Desktop ### Bugfixes - Reduced composer lag when drafts include large pasted images or attachments. - Let project search match any known recent project instead of only the first five. (@NumerousJLs) - Cleared stale assistant errors from the timeline once the same turn resumes streaming. - Skipped legacy config reads against v2 servers to avoid spurious config loading issues. (@resetsix) **Thank you to 4 community contributors:** - @resetsix: - fix(app): skip legacy config reads for v2 (#40211) - @NumerousJLs: - fix(app): search every known project in the open project dialog (#40202) - @MagnumGoYB: - docs: remove obsolete vouch system section (#40266) - @frederiknsgo: - fix: gpt-5.5+ in combination with azure fails with reasoningEffort (#40265)

## ¿Por qué importa? 🛡️

> [!success] Impacto
>
> - Corrige fallos en solicitudes de completado de Azure GPT-5.5+ cuando el razonamiento está habilitado.
> - Mejora el rendimiento del escritorio al reducir la latencia del compositor con imágenes grandes o adjuntos.
> - Incluye correcciones adicionales para la búsqueda de proyectos y la gestión de errores en la línea de tiempo.

## 📜 Informe para desarrolladores

> [!info] ¿Qué es?
>
> Opencode es una herramienta de asistencia de código basada en IA, integrada en una aplicación de escritorio, que permite usar modelos como GPT-5.5 en Azure para completar código y gestionar proyectos.

> [!tip] ¿En qué ayuda al desarrollo?
>
> Mejora la productividad al automatizar completaciones de código, reducir latencia en la interfaz y facilitar la búsqueda y gestión de proyectos recientes.

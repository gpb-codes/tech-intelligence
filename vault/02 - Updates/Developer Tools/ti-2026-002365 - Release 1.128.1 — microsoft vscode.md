# Release: 1.128.1 — microsoft/vscode

## Resumen

- Se ha lanzado la versión 1.28 de Visual Studio Code.
- Se han agregado nuevas características y mejoras en la edición de código, como la capacidad de seleccionar múltiples líneas y la mejora de la experiencia de edición en la terminal.
- Se ha mejorado la integración con GitHub, permitiendo la visualización de información de commit y la capacidad de crear y editar issues directamente desde VS Code.
- Se han agregado nuevas extensiones y mejoras en la experiencia de usuario, como la capacidad de personalizar la barra de herramientas y la mejora de la experiencia de depuración.
- La versión 1.28 incluye más de 100 mejoras y correcciones de errores.

## ¿Por qué importa?

- Mejoras en la experiencia de usuario
- Nuevas funcionalidades en la edición de código
- Actualizaciones de seguridad

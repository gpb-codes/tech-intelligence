# Release: 1.130.0 — microsoft/vscode

## Resumen

- Se ha lanzado la versión 1.30 de Visual Studio Code.
- Se han agregado nuevas características y mejoras en la edición de código, incluyendo la capacidad de editar múltiples archivos al mismo tiempo.
- Se ha mejorado la integración con GitHub, permitiendo una mayor eficiencia en la gestión de repositorios.
- Se han agregado nuevas extensiones y mejoras en la experiencia de usuario.
- La versión 1.30 incluye mejoras en la seguridad y estabilidad del producto.

# Release: v2.1.232 — anthropics/claude-code

<span class="ti-runes">ᚠ ᚢ ᚦ ᚨ ᚱ ᚲ</span>

> [!abstract] Resumen
>
> - Se lanzó la versión **v2.1.232** de **Claude Code** (anthropics/claude-code), activando por defecto el subagente de bifurcación ("fork") con herencia de conversación y caché, y permitiendo menciones `@` entre sesiones interactivas para comunicación directa vía `SendMessage`.
> - Se añadió **soporte nativo para GitLab** en marketplaces de plugins (clonado de URLs, subgrupos anidados, pistas de autenticación) y ofuscación de secretos para múltiples familias de tokens de GitLab (`glpat-`, `glrt-`, etc.), equiparando su protección a la de GitHub (`gh`).
> - Se corrigieron **múltiples bypasses de seguridad y permisos**: en PowerShell (sobrescritura de `$PSDefaultParameterValues`), Windows Git Bash (symlinks estilo Cygwin), herencia de `trust` en repositorios anidados, y endurecimiento del sandbox de Linux y directorio de sockets `/tmp` contra ataques de symlink.
> - Mejoras de **fiabilidad en Remote Control y Gateway**: reconexión tras caídas de red (~30 min), reanudación correcta de sesiones eliminadas (regresión v2.1.227), recarga automática de certificados mTLS rotados sin reinicio, y validación estricta de configuraciones de arranque (grupos vacíos, dominios de email malformados, claves `desktop:` desconocidas).
> - Optimizaciones de **rendimiento y UX**: streaming en pantalla completa sin renormalización completa por actualización, lectura no bloqueante de imágenes del portapapeles, apertura inmediata de `/feedback` y `/bug`, actualización automática de marketplace al instalar plugins, y correcciones visuales de truncamiento y emojis.

> ## Qué cambió -
> 
> - El subagent de bifurcación ahora está activado por defecto: un subagent con `subagent_type: "fork"` hereda la conversación completa y la caché de prompts, y los spawns de agentes no compañeros en sesiones interactivas ahora se ejecutan en segundo plano por defecto
> - Escribe `@` en el prompt para mencionar otra sesión de Claude por nombre; Claude usa entonces `SendMessage` para alcanzar esa sesión directamente
> - `SendMessage` ahora entrega a un `bare name` que coincide exactamente con una sesión activa, en lugar de pedir confirmación con una referencia primero
> - Las sesiones interactivas en una misma máquina ahora mantienen nombres únicos: al iniciar o renombrar una sesión con un nombre que ya usa otra sesión activa, se le asigna una variante `name-word-word` y se lo notifica
> - Se añadieron filas `/config` para "Dialog expiry" y "Messages from your other sessions" (aceptar/retener/rechazar en entrada entre sesiones)
> - Se añadió ofuscación de secretos para familias de tokens de GitLab (`glrt-`, `gloas-`, `glptt-`, `glagent-`, `glimt-`, `glsoat-`, `glcbt-`, `glft-`, `glffct-`) y ofuscación completa de tokens routables `glpat-`/`gldt-`; la tienda de configuración CLI `glab` obtiene la misma protección de sandbox y ruta de credenciales que `gh`
> - Se añadió soporte de GitLab a los marketplaces de plugins: ahora las URLs de repositorio sin formato `gitlab.com` (incluyendo `nested subgroups`) se clonan como las URLs de `github.com`, y las pistas de `auth-failure` nombran tu host git real
> - Configuración: `additionalMarketplaces` y `allowedMarketplaces` ahora se aceptan como aliases más amigables para `extraKnownMarketplaces` y `strictKnownMarketplaces`
> - Política empresarial: una entrada `blockedMarketplaces` tipada por URL para una ruta de repositorio sin formato mantiene el bloqueo de esa URL cuando el CLI la clasifica como una clonación git
> - Gateway: el superposición `desktop:` ahora acepta cada configuración de Desktop lanzada (era 11 llaves listadas a mano), validada al arrancar contra el propio esquema de Desktop; claves desconocidas o inválidas fallan al arranque
> - Gateway: entradas vacías en `managed.policies[].match.groups`/`admin.admin_groups` y valores `email_domain` malformados (vacíos, o que contengan `@`, espacios en blanco o comas) ahora fallan al arrancar en lugar de coincidir silenciosamente con nadie o conceder acceso de administrador
> - Fable 5 se ofrece como asesor en `/advisor` nuevamente para organizaciones con acceso a Fable, con consentimiento de créditos de uso configurado a través de `/model fable`
> - Corregido un bypass de permisos de PowerShell donde los parámetros de escritura de variables podían sobrescribir silenciosamente `$PSDefaultParameterValues` y redirigir el acceso a archivos de comandos posteriores
> - Corregido un bypass de permisos en Windows donde Git Bash siguió symlinks estilo Cygwin que la validación de ruta veía como archivos regulares; las escrituras a través de ellos ahora requieren aprobación de permisos
> - Corregido que repositorios anidados de git heredaran `trust` de un directorio padre; cada repositorio ahora requiere su propia confirmación de `trust`
> - Corregidas las conexiones MCP que se colgaban durante el tiempo completo de timeout de conexión de 30 segundos cuando un servidor no responde o envía una respuesta malformada al sondeo de protocolo-version
> - Corregidas las sesiones de Remote Control hospedadas por un puente dentro de una sesión de nube que heredaban el transcript o las credenciales de esa sesión
> - Corregidas las sesiones de Remote Control iniciadas desde Claude Desktop o un IDE que aparecían como una nueva sesión de claude.ai cada vez que se reanudaba la sesión local; ahora se reanudan la existente
> - Corregidas las sesiones de Remote Control que aparecían inalcanzables para clientes recién adjuntos mientras estaban inactivas
> - Corregidas las sesiones de puente de Remote Control que no restauraban el historial de conversación cuando el trabajador de la sesión se reinicia
> - Remote Control: reanudar una conversación cuya sesión fue eliminada de claude.ai o la app ahora inicia un reemplazo en lugar de fallar con un mensaje sobre tu inicio de sesión (regressado en v2.1.227)
> - Corregido el gateway en la nube `/login` que salía en silencio o dejaba un terminal sin respuesta después de `Press Enter to continue` cuando fallaba la carga de configuraciones gestionadas; ahora se muestra el motivo
> - Corregido el modo voz en compilaciones nativas que se quedaba atascado en `listening…` cuando el servicio de voz rechazaba la conexión; el rechazo ahora se muestra inmediatamente
> - Corregida la rotación de certificados mTLS que requería un reinicio; Claude Code ahora recarga el certificado y la clave rotados automáticamente en errores de conexión
> - Corregidos valores de región malformados de AWS o Vertex que se usaban para construir URLs de solicitud; ahora caen de regreso a la región predeterminada
> - Corregidos errores de timeout idle de transmisión que fallaban la solicitud en lugar de recuperarse en despliegues de Bedrock, Vertex y gateway
> - Corregidos superposiciones de tamaño de contenido que contienen texto truncado que renderizan una columna demasiado ancho, y texto truncado al inicio que se colapsa a una `ellipsis`
> - Corregido un carácter basura donde un comando de shell largo o una vista previa de descripción de agente se cortaba a mitad de un emoji
> - Corregida una carrera de inicio que podría descargar sin registro un marketplace de plugins por escrituras concurrentes a `known_marketplaces.json`
> - Corregido `/update` y `/tui` negándose a reiniciar mientras el trabajo que sobrevive al reinicio estaba en ejecución
> - Corregida la orientación de límites de uso que sugería `slash commands` no disponibles en SDK y sesiones remotas
> - Corregido el mensaje de consentimiento para lanzamientos interactivos de `--advisor fable`, que te indicaba ejecutar `/model fable` en una sesión interactiva que acababa de salir
> - Mejorado el streaming en pantalla completa: sesiones largas se mantienen responsivas porque la conversación completa ya no se vuelve a normalizar en cada actualización
> - Mejorado el diálogo de aprobación de configuraciones gestionadas: muestra URLs de extremos, usa una redacción más clara para cambios solo de telemetría, omite opciones rutinarias de OpenTelemetry, y requiere aprobación para sobrescripciones de binario de sandbox gestionado por el servidor (`sandbox.bwrapPath`, `sandbox.socatPath`, `sandbox.ripgrep`)
> - `/feedback` y `/bug` ahora se abren inmediatamente cuando se invocan mientras Claude está respondiendo, en lugar de esperar a que termine el turno
> - `/plugin install plugin@marketplace` ahora actualiza el marketplace primero, así los plugins recién publicados se instalan sin una actualización manual del marketplace
> - `/code-review` en alto, xhigh y max ahora se ejecuta en un `background agent` como los demás niveles
> - Las imágenes pegadas y del portapapeles se leen sin bloquear el `event loop`
> - Remote Control ahora vuelve a conectar durante unos 30 minutos después de un `network blip` y ya no se desconecta después de unos pocos fallos extendidos en una hora
> - Remote Control: reanudar una conversación ya no quita silenciosamente el Remote Control a otro Claude Code en la misma máquina que aún lo tiene; ejecuta `/remote-control` allí para moverlo
> - Panel de actualización de agentes: los subagents completos se ocultan inmediatamente con una pista de pie `/tasks`, y el indicador de desbordamiento `overflow indicator` se movió a la izquierda para visibilidad
> - Remote Control: el terminal ahora indica si una sesión fue tomada por otro dispositivo, finalizada desde otra app o eliminada, y deja de sugerir una reconexión `reconnect` que la desharía
> - Las redirecciones de entrada de Bash (`< archivo`) ahora se verifican permisos como sus ortografías de argumento en todas las plataformas
> - Acortado el mensaje que se muestra al reanudar un `background agent` completado
> - Las sesiones de cowork ya no incrustan importaciones externas `@-imports` de archivos de memoria de ámbito de usuario
> - Endurecido el directorio de socket de mensajería entre sesiones `cross-session` en `/tmp` compartido: un `symlink` plantado previamente o el directorio de otro usuario ahora se niega en lugar de usarse
> - Endurecido el sandbox de Linux contra un `bypass` de ruta protegida
> - Cambió `sandbox.ripgrep` para que solo se honre desde configuraciones de usuario, gestionadas y `--settings`; las configuraciones de proyecto ya no pueden anular el binary de ripgrep del sandbox
> - Eliminado el consejo de inicio que sugería crear `subagents` personalizados, y la nudge coincidente en el tour `/powerup`

## 📜 Informe para desarrolladores

> [!info] ¿Qué es?
>
> Claude Code es una herramienta de línea de comandos (CLI) basada en IA que funciona como un agente de programación para asistir a desarrolladores en la escritura y gestión de código. La versión v2.1.232 introduce mejoras en la gestión de sesiones, soporte para GitLab y endurecimiento de la seguridad.

> [!tip] ¿En qué ayuda al desarrollo?
>
> Facilita el desarrollo de software al ejecutar agentes en segundo plano y automatizar tareas como la revisión de código (/code-review). Además, mejora la colaboración entre sesiones y la seguridad mediante la ofuscación de secretos y el endurecimiento del sandbox, creando entornos más eficientes y seguros.

## What's changed - Subagent forking is now on by default: a `subagent_type: "fork"` subagent inherits the full conversation and prompt cache, and non-teammate agent spawns in interactive sessions now run in the background by default - Type `@` in the prompt to mention another Claude session by name; Claude then uses `SendMessage` to reach that session directly - `SendMessage` now delivers to a bare name that exactly matches one live session, instead of asking to confirm with a ref first - Interactive sessions on one machine now keep unique names: starting or renaming a session to a name another live session already uses gives it a `name-word-word` variant and tells you - Added `/config` rows for "Dialog expiry" and "Messages from your other sessions" (cross-session inbound accept/hold/refuse) - Added secret redaction for GitLab token families (`glrt-`, `gloas-`, `glptt-`, `glagent-`, `glimt-`, `glsoat-`, `glcbt-`, `glft-`, `glffct-`) and full redaction of routable `glpat-`/`gldt-` tokens; the `glab` CLI config store gets the same sandbox and credential-path protection as `gh` - Added GitLab support to plugin marketplaces: bare `gitlab.com` repo URLs (including nested subgroups) now clone like `github.com` URLs, and clone auth-failure hints name your actual git host - Settings: `additionalMarketplaces` and `allowedMarketplaces` are now accepted as friendlier aliases for `extraKnownMarketplaces` and `strictKnownMarketplaces` - Enterprise policy: a url-typed `blockedMarketplaces` entry for a bare repo URL keeps blocking that URL when the CLI classifies it as a git clone - Gateway: the `desktop:` overlay now accepts every released Desktop setting (was 11 hand-listed keys), validated at boot against Desktop's own schema; unknown or invalid keys fail boot - Gateway: empty `managed.policies[].match.groups`/`admin.admin_groups` entries and malformed `email_domain` values (empty, or containing `@`, whitespace, or commas) now fail at boot instead of silently matching no one or granting admin access - Fable 5 is offered as an advisor in `/advisor` again for organizations with Fable access, with usage-credits consent set up through `/model fable` - Fixed a PowerShell permission bypass where variable-writing parameters could silently overwrite `$PSDefaultParameterValues` and redirect later commands' file access - Fixed a Windows permission bypass where Git Bash followed Cygwin-style symlinks that path validation saw as regular files; writes through them now require permission approval - Fixed nested git repositories inheriting trust from a parent directory; each repository now requires its own trust confirmation - Fixed MCP connections hanging for the full 30-second connect timeout when a server fails to answer or sends a malformed reply to the protocol-version probe - Fixed Remote Control sessions hosted by a bridge inside a cloud session inheriting that session's transcript or credentials - Fixed Remote Control sessions started from Claude Desktop or an IDE appearing as a new claude.ai session each time the local session was resumed; they now reattach to the existing one - Fixed Remote Control sessions appearing unreachable to newly attached clients while idle - Fixed Remote Control bridge sessions not restoring conversation history when the session worker restarts - Remote Control: resuming a conversation whose session was deleted from claude.ai or the app now starts a replacement instead of failing with a message about your login (regressed in v2.1.227) - Fixed Cloud gateway `/login` exiting silently or leaving an unresponsive terminal after "Press Enter to continue" when managed settings failed to load; the reason is now shown - Fixed voice mode on native builds getting stuck on "listening…" when the voice service rejected the connection; the rejection is now shown immediately - Fixed mTLS client certificate rotation requiring a restart; Claude Code now reloads the rotated cert and key automatically on connection errors - Fixed malformed AWS or Vertex region values being used to build request URLs; they now fall back to the default region - Fixed stream idle timeout errors failing the request instead of recovering on Bedrock, Vertex, and gateway deployments - Fixed content-sized overlays containing truncated text rendering one column too wide, and start-truncated text collapsing to an ellipsis - Fixed a stray garbled character where a long shell-command or agent-description preview was cut off mid-emoji - Fixed a startup race that could silently unregister a plugin marketplace due to concurrent writes to `known_marketplaces.json` - Fixed `/update` and `/tui` refusing to restart while work that survives the relaunch was running - Fixed usage-limit guidance suggesting unavailable slash commands in SDK and remote sessions - Fixed the consent message for interactive `--advisor fable` launches, which told you to run `/model fable` in an interactive session that had just exited - Improved fullscreen streaming: long sessions stay responsive because the whole conversation is no longer re-normalized on every update - Improved the managed settings approval dialog: shows endpoint URLs, uses clearer wording for telemetry-only changes, skips routine OpenTelemetry options, and requires approval for server-managed sandbox binary overrides (`sandbox.bwrapPath`, `sandbox.socatPath`, `sandbox.ripgrep`) - `/feedback` and `/bug` now open immediately when invoked while Claude is responding, instead of waiting for the turn to finish - `/plugin install plugin@marketplace` now refreshes the marketplace first, so newly published plugins install without a manual marketplace update - `/code-review` at high, xhigh, and max effort now runs in a background agent like the other levels - Pasted and clipboard images are read without blocking the event loop - Remote Control now keeps reconnecting for about 30 minutes after a network blip and no longer drops after a few blips spread across an hour - Remote Control: resuming a conversation no longer silently takes Remote Control away from another Claude Code on the same machine that still has it; run `/remote-control` there to move it - Updated agent panel: completed subagents hide immediately with a `/tasks` footer hint, and the "↓ N more" overflow indicator moved left for visibility - Remote Control: the terminal now says whether a session was taken over by another device, ended from another app, or deleted, and stops suggesting a reconnect that would undo it - Bash input redirections (`< file`) are now permission-checked like their argument spellings on all platforms - Shortened the message shown when resuming a completed background agent - Cowork sessions no longer inline external @-imports from user-scope memory files - Hardened the auto-generated cross-session messaging socket directory on shared `/tmp`: a pre-planted symlink or another user's directory is now refused instead of used - Hardened the Linux filesystem sandbox against a protected-path bypass - Changed `sandbox.ripgrep` to be honored only from user, managed, and `--settings` settings; project settings can no longer override the sandbox's ripgrep binary - Removed the startup tip suggesting you create custom subagents, and the matching nudge in the `/powerup` tour

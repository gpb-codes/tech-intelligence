# D7VK 2.1 Brings Faster Load Times, More Performance Tweaks

> [!abstract] Resumen
>
> - Se lanzó D7VK 2.1, una actualización de la implementación open-source de las APIs Direct3D 7, 6, 5 y 3 sobre Vulkan para Linux/Wine.
> - La versión introduce tiempos de carga más rápidos y nuevos ajustes de rendimiento.
> - D7VK complementa a DXVK (Direct3D 8-11) y VKD3D-Proton (Direct3D 12) cubriendo las versiones más antiguas de la API de Microsoft.
> - El proyecto sigue madurando para mejorar la compatibilidad y ejecución de juegos y aplicaciones basadas en Direct3D legado en Linux.

## ¿Qué ocurrió? ⚔️

> [!info] Traducción del anuncio
>
> D7VK 2.1 Trae tiempos de carga más rápidos, más ajustes de rendimiento
> 
> D7VK como la open-source implementation of the Direct3D 7 / 6 / 5/ 3 APIs sobre la Vulkan API para uso en Linux/Wine tiene otra actualización de características. D7VK continúa madurando bastante bien para mejorar aún más estas versiones de API Direct3D más antiguas que abarcan el rango previo al enfoque de DXVK de Direct3D 8 a Direct3D 11 o VKD3D-Proton's Direct3D 12...

## ¿Por qué importa? 🛡️

> [!success] Impacto
>
> - Versión 2.1 incluye tiempos de carga más rápidos y ajustes de rendimiento
> - Continúa la maduración de la implementación open-source de APIs Direct3D 7/6/5/3 sobre Vulkan
> - Diseñado para mejorar compatibilidad y rendimiento en plataformas Linux/Wine con APIs Direct3D anteriores a DXVK

## 📜 Informe para desarrolladores

> [!info] ¿Qué es?
>
> D7VK es una implementación de código abierto de las APIs de Direct3D 7, 6, 5 y 3 sobre la API Vulkan para su uso en Linux y Wine. La versión 2.1 trae tiempos de carga más rápidos y más ajustes de rendimiento para estas antiguas APIs gráficas.

> [!tip] ¿En qué ayuda al desarrollo?
>
> Facilita el desarrollo y soporte de software legado al permitir ejecutar aplicaciones con APIs Direct3D antiguas en sistemas Linux mediante Wine. Sus mejoras en tiempos de carga y rendimiento en la versión 2.1 optimizan la experiencia y viabilidad de estos sistemas en plataformas modernas.

# IOmap Improvement For Linux 7.3 Takes EXT4 & XFS Performance Further

> [!abstract] Resumen
>
> - Se fusionó una mejora en el marco IOmap al kernel de desarrollo de Linux 7.3 como parte de las pull requests de VFS.
> - La tecnología involucrada es el marco IOmap, utilizado por sistemas de archivos como EXT4 y XFS para mapear desplazamientos de bytes lógicos de archivos a ubicaciones físicas en almacenamiento.
> - Es relevante porque este marco de mapeo de bloques ahora permite un mejor rendimiento en al menos el sistema de archivos EXT4.

## ¿Qué ocurrió? ⚔️

> [!info] Traducción del anuncio
>
> Mejora de IOmap para Linux 7.3 Lleva el Rendimiento de EXT4 y XFS Más Lejos
> 
> Como parte de las pull requests de VFS ahora fusionadas al kernel de desarrollo de Linux 7.3, se incluyó una mejora en el marco IOmap utilizado por varios sistemas de archivos para mapear desplazamientos de bytes lógicos de archivos en memoria a sus ubicaciones físicas en el almacenamiento. Con el código ahora fusionado, este moderno marco de mapeo de bloques está permitiendo un mejor rendimiento al menos para el sistema de archivos EXT4...

## ¿Por qué importa? 🛡️

> [!success] Impacto
>
> - Mejora del marco IOmap fusionada en Linux 7.3 para mapeo de bloques moderno
> - Permite mejor rendimiento en sistemas de archivos EXT4 y XFS ampliamente utilizados
> - Parte de pull requests de VFS que afectan funcionalidad central del kernel

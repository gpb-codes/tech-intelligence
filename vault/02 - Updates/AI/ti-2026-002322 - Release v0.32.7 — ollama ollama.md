> [!abstract] Resumen
>
> - Se lanzó la versión v0.32.7 de Ollama, que incluye soporte inicial para el modelo Muse Glimmer.  
> - Muse Glimmer es un modelo multimodal de 30B creado por Meta Superintelligence Labs, diseñado para cargas de trabajo de agentes locales.  
> - Su disponibilidad se activa inicialmente mediante el motor MLX, optimizado para Apple Silicon, con planes de expansión a NVIDIA, AMD y otras plataformas.  
> - La versión introduce mejoras como soporte DFlash y entrada de imágenes, ampliando las capacidades locales de IA.  
> - Es relevante al permitir ejecutar localmente modelos de alto rendimiento para agentes de codificación y asistentes personales sin dependencia de la nube.

## ¿Qué ocurrió? ⚔️

> [!info] Traducción del anuncio
>
> Release: v0.32.7 — ollama/ollama
> 
> ## Muse Glimmer > Nota: Muse Glimmer está actualmente disponible mediante soporte inicial a través del motor MLX de Ollama en Apple Silicon. Se añadirán soportes y optimizaciones adicionales para Apple Silicon, NVIDIA, AMD y otras plataformas en los próximos días. **Muse Glimmer**, el nuevo modelo abierto de Meta y el primero lanzado por Meta Superintelligence Labs, ya está disponible en Ollama. Es un modelo multimodal de 30B diseñado específicamente para cargas de trabajo de agentes que se ejecutan localmente. Con Ollama, ahora puedes usar Muse Glimmer para impulsar aplicaciones de agentes de codificación como Claude Code, Codex, Pi y más, así como asistentes personales de larga duración como OpenClaw y Hermes. El motor MLX de Ollama proporciona un rendimiento de vanguardia en Apple Silicon para este modelo, con soporte para DFlash y entrada de imágenes a partir de Ollama 0.32.7. Para descargar y ejecutar Muse Glimmer localmente: ```bash ollama run muse-glimmer:30b-mlx ``` Para ejecutar Muse Glimmer en Apple Silicon con Claude Code, [descarga Ollama](https://ollama.com/download) y ejecuta: ```bash ollama launch claude --model muse-glimmer:30b-mlx ``` Para un agente de codificación más ligero, prueba [Pi](https://pi.dev): ```bash ollama launch pi --model muse-glimmer:30b-mlx ``` Para frameworks de asistentes personales como OpenClaw y Hermes, usa: ```bash ollama launch openclaw --model muse-glimmer:30b-mlx ``` ```bash ollama launch hermes --model muse-glimmer:30b-mlx ```

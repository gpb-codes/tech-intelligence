# Release: v0.32.9 — ollama/ollama

> [!abstract] Resumen 🛡️
> Ollama v0.32.9 añade soporte para NVIDIA Nemotron 3.5 Lightning, un modelo abierto MoE de 30B con 3B activos para agentes siempre activos, y la arquitectura Nemotron 3. También corrige un caso límite en el parser de llamadas a funciones de Muse Glimmer.

## ¿Qué ocurrió? ⚔️

> [!info] Traducción del anuncio
> La release v0.32.9 de Ollama introduce el modelo abierto NVIDIA Nemotron 3.5 Lightning, un MoE de 30B parámetros con 3B activos pensado para la capa de ejecución de agentes siempre activos, compatible con harnesses como OpenClaw y Hermes Agent y con el stack abierto NemoClaw de NVIDIA. Además, añade la arquitectura Nemotron 3 y arregla un caso límite en el parser de Muse Glimmer.

## ¿Por qué importa? 🛡️

> [!success] Impacto
> - Los modelos MoE eficientes hacen viable la ejecución local de agentes.
> - El ecosistema abierto (OpenClaw, NemoClaw) refuerza la capa de agentes autónomos.

## 📜 Informe para desarrolladores

> [!info] ¿Qué es?
> Una release de Ollama con soporte del modelo NVIDIA Nemotron 3.5 Lightning, abierto, MoE de 30B con 3B activos, para agentes siempre activos.

> [!tip] ¿En qué ayuda al desarrollo?
> Permite probar `ollama run nemotron-3.5-lightning` y desplegar agentes persistentes de bajo consumo en local.

# Release: v0.32.8 — ollama/ollama

> [!abstract] Resumen
>
> - Lanzamiento de Ollama v0.32.8, que introduce el modelo Muse Glimmer.  
> - Muse Glimmer está disponible en todas las plataformas y puede impulsar agentes de codificación y asistentes personales.  
> - El motor MLX ofrece rendimiento de vanguardia en Apple Silicon, con soporte para DFlash y entrada de imágenes (desde la versión 0.32.7).  
> - Se amplía la compatibilidad con NVIDIA, AMD y otras plataformas, según el changelog.  
> - Se proporcionan comandos para ejecutar el modelo localmente o integrarlo con herramientas como Claude Code, Pi, OpenClaw y Hermes.

## ¿Qué ocurrió? ⚔️

> [!info] Traducción del anuncio
>
> Lanzamiento: v0.32.8 — ollama/ollama
> 
> ## Muse Glimmer Muse Glimmer ahora está disponible en todas las plataformas. Muse Glimmer puede impulsar aplicaciones de agentes de codificación como Claude Code, Codex, Pi y más, así como asistentes personales de larga duración como OpenClaw y Hermes. El motor MLX de Ollama proporciona un rendimiento de vanguardia en Apple Silicon para este modelo, con soporte para DFlash y entrada de imágenes a partir de Ollama 0.32.7. Para descargar y ejecutar Muse Glimmer localmente: ```bash ollama run muse-glimmer ``` Para ejecutar Muse Glimmer con Claude Code, [descargue Ollama](https://ollama.com/download) y ejecute: ```bash ollama launch claude --model muse-glimmer ``` Para un agente de codificación más ligero, pruebe [Pi](https://pi.dev): ```bash ollama launch pi --model muse-glimmer ``` Para frameworks de asistentes personales como OpenClaw y Hermes, use: ```bash ollama launch openclaw --model muse-glimmer ``` ```bash ollama launch hermes --model muse-glimmer ``` ## What's Changed * Add Muse Glimmer support for NVIDIA, AMD, and additional platforms **Full Changelog**: https://github.com/ollama/ollama/compare/v0.32.7...v0.32.8

## ¿Por qué importa? 🛡️

> [!success] Impacto
>
> - Lanzamiento de Muse Glimmer, un modelo ML compatible con múltiples plataformas (NVIDIA, AMD, Apple Silicon) y aplicaciones de agentes de codificación y asistentes personales.
> - Integración con herramientas clave como Claude Code, Codex, Pi, OpenClaw y Hermes, ampliando su adopción en ecosistemas de desarrollo.
> - Mejoras en rendimiento en Apple Silicon mediante el motor MLX de Ollama, incluyendo soporte para DFlash y entrada de imágenes desde la versión 0.32.7.

## 📜 Informe para desarrolladores

> [!info] ¿Qué es?
>
> Ollama es una plataforma para ejecutar modelos de lenguaje grandes (LLM) localmente. La versión 0.32.8 añade soporte multiplataforma para el modelo Muse Glimmer, optimizado con motor MLX en Apple Silicon e integra agentes de codificación (Claude Code, Codex, Pi) y asistentes personales (OpenClaw, Hermes).

> [!tip] ¿En qué ayuda al desarrollo?
>
> Facilita el desarrollo al permitir ejecutar modelos de IA potentes sin depender de la nube, reduce latencia y costos, y permite integrar asistentes de código y agentes autónomos directamente en flujos de trabajo locales, acelerando la prototipación y pruebas.
